# Consciousness as Interpretation

A Coupling Model of Consciousness (the Interpreter Model).

Published record: https://doi.org/10.5281/zenodo.24358525

## Files

- `revised.pdf`: the paper
- `revised.tex`, `body_revised.tex`, `appendices_revised.tex`, `references.bib`: LaTeX sources
- `zenodo_abstract.txt`: abstract
- `simulations/`: scripts that produce the figures and tables in `data/`
- `data/`: computed values, figures, and the 1JFF tubulin structure used by the geometric calculation

Build with `latexmk -pdf revised.tex`.

This work was heavily AI-assisted. The idea, the composition of the model, and the line of argument are the author's own.
